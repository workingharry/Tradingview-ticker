### 1. 啟動、視窗標題與 Dock 名稱
- **操作步驟**：從 `/Applications/` 或 Spotlight 開啟 **Momentum Swing Terminal.app**。
- **預期結果**：App 在數秒內正常開啟，視窗標題與 Dock 圖示名稱皆顯示為 **Momentum Swing Terminal**，狀態徽章顯示已連線，無閃退或空白畫面。
- **檢查**：`[ ] 通過`

### 2. 自選股（Watchlist）完整性、順序與標籤
- **操作步驟**：檢查右側自選股清單，對照先前在舊版（`TradingView Terminal`）的自選股列表、排序、釘選（Pin）與群組顏色／標籤。
- **預期結果**：自選股數量（13 檔，含您先前新增與排序）、順序、釘選狀態及顏色標籤皆與舊版完全一致。
- **檢查**：`[ ] 通過`

### 3. 繪圖、價位線、`$ Risk` 與自訂選股 Preset（WebKit `localStorage` 遷移與繪圖互動驗證）
- **操作步驟**：
  1. 在自選股中**任選 2 檔先前有畫線的股票**，切換過去檢視圖表，並切換一次時間週期（如 `1D` → `1W` → `1h` → `1D`）。
  2. 確認先前建立的水平價位線（Price Lines）。
  3. 檢查上方／計算機的 **`$ Risk`** 預設風險金額欄位。
  4. 開啟 **選股器（Screener）**，檢查頂部「自訂策略 Preset」列。
  5. 從 **`ƒx 指標 (Indicators)`** 開啟「顯示左側繪圖工具欄」，在 K 棒區與右側留白區放置一個 R:R 框：
     - 分別切換趨勢線 / 水平線 / 測量尺，在 R:R 框內進行**點兩下畫線**與**按住拖曳（≥ 6px）畫線**，並確認非 `cursor` 模式下直接點擊 R:R 框 `✕` 不會刪除框且游標維持十字準心（`crosshair`）。
     - 在畫線進行中（已有起點預覽）按第一次 `Esc`，檢查是否僅取消當前線段並保留所選工具；無進行中線段時按第二次 `Esc` 是否退回 `cursor`。
- **預期結果**：
  - 2 檔股票的既有繪圖、趨勢線與 R:R 框皆完整存在，切換週期（`1D` → `1W` → `1h` → `1D`）後位置合理且不消失。
  - 價位線仍在正確價位上、`$ Risk` 數值與舊版最後設定一致、自訂選股 preset 皆完整保留。
  - K 棒區與右側留白區的 R:R 框內皆可順利以點兩下或拖曳畫出趨勢線 / 水平線 / 尺；非 `cursor` 模式點擊 `✕` 不會刪框；兩段式 `Esc` 行為正確。
- **檢查**：`[ ] 通過`

### 4. 多週期切換與 K 棒載入（`1m` / `15m` / `1h` / `1D` / `1W`）
- **操作步驟**：依序點擊工具列上的 `1m`、`15m`、`1h`、`1D`、`1W` 按鈕。
- **預期結果**：各週期皆能正常切換並顯示 K 棒與成交量，無長期空白圖或卡死現象（`1D`/`1W` 具備完整長歷史）。
- **檢查**：`[ ] 通過`

### 5. 即時報價跳動
- **操作步驟**：於美股開盤時段觀察美股標的，或點擊加密貨幣標的（如 `BINANCE:BTCUSDT`）觀察 24 小時即時行情約 15–30 秒。
- **預期結果**：最新價格、漲跌幅與當前未收盤 K 棒隨即時成交跳動更新，右上角／選單列顯示正常更新。
- **檢查**：`[ ] 通過`

### 6. 自選股搜尋、新增、排序與跨重啟持久化
- **操作步驟**：
  1. 用搜尋列（Omnibox）搜尋一檔不在清單內的股票並點擊加入自選股。
  2. 拖曳調整該股票順序，接著從清單刪除它（或保留一檔測試用標的）。
  3. 完全退出 App（`Cmd+Q`），再次開啟。
- **預期結果**：重開後的自選股清單、順序與剛才操作後的狀態完全一致（建議驗完再恢復您習慣的清單）。
- **檢查**：`[ ] 通過`

### 7. 部位計算機手算核對
- **操作步驟**：開啟繪圖工具中的 **Risk/Reward (R:R)** 工具或部位計算欄位，輸入資金／`$ Risk`（例如風險金額設為 `1000`，代表 100,000 資金的 1%）、進場價 `50`、停損價 `47`、目標價 `56`。
- **預期結果**：計算出的建議股數為 **`333` 股**（`floor(1000 / (50 - 47)) = 333`），R:R 顯示 `1 : 2.00`，與手算結果完全吻合。
- **檢查**：`[ ] 通過`

### 11. AI 功能（有/無 API Key 行為）
- **操作步驟**：
  1. 點擊上方工具列的 **`ƒx 指標 (Indicators)`** 選單，勾選啟用分析工具（顯示 **財報分析** 與 **AI Lens** 按鈕）。
  2. 點擊工具列出現的 **`🤖 AI Lens`** 或 **`📊 財報分析`** 按鈕。
  - 若有設定 `GEMINI_API_KEY`（如透過 `launchctl setenv GEMINI_API_KEY ...`）：檢查 AI 分析回應。
  - 若未設定金鑰：檢查系統回應與介面底部／狀態標籤。
- **預期結果**：有金鑰時正常回傳 Gemini 分析；無金鑰時應快速降級並明確顯示 **`Rule-Based (Offline)`** 離線規則分析結果，不會報 500 錯誤或無限轉圈卡住（工具列按鈕不應折行或被截斷）。
- **檢查**：`[ ] 通過`

### 12. 離線啟動測試（涵蓋 R4 離線項目）
